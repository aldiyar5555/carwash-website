# Premium Car Wash Landing Page 🚗✨

Современный, адаптивный одностраничный сайт (Landing Page) для премиальной автомойки в Астане.

### 🌟 Ключевые особенности:
* [cite_start]**Современный UI/UX**: использование шрифтов Google Fonts (Poppins) и плавных CSS-анимаций. 
* [cite_start]**Адаптивность**: сайт полностью оптимизирован под мобильные устройства, планшеты и десктопы. 
* [cite_start]**Интерактивность**: плавный скролл к секциям, эффект наведения на карточки услуг и кнопка связи через WhatsApp. 
* [cite_start]**Чистый код**: семантическая верстка на HTML5 и структурированный CSS3 с использованием переменных. 

### 🛠 Стек технологий:
* [cite_start]**HTML5**: семантическая структура. 
* [cite_start]**CSS3**: Flexbox, Grid, Custom Properties, Transitions. 
* [cite_start]**FontAwesome**: профессиональный набор иконок. 
* [cite_start]**Google Fonts**: типографика премиум-класса. 

### 📂 Структура проекта:
* [cite_start]`index.html` — основная разметка сайта. 
* [cite_start]`style.css` — стили и анимации. 
* [cite_start]`.gitignore` — настроен для исключения системного мусора.
